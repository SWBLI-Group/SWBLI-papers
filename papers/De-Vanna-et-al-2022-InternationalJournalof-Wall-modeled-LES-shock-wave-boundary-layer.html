01中文摘要

壁面模化大涡模拟（WMLES）把近壁湍流交给壁模型、把外层大尺度涡结构交给 LES 解析，是工程尺度高雷诺数激波/边界层干扰的有希望途径。本文围绕典型压缩拐角/入射激波干扰构型，将壁面模化 LES 与全解析数值结果及实验数据对比，评估壁模型在逆压梯度、分离与再附条件下的表现，分析网格分辨率、壁模型类型和来流条件对分离泡长度、壁面压力、摩阻与热流预测的影响，并讨论 WMLES 在峰值传热预测中的不确定性与改进方向。

02研究背景与问题

高雷诺数激波/边界层干扰的直接数值模拟代价过高，RANS 又难以准确预测分离泡和峰值热流，壁面模化 LES 因而成为折中方案。但壁模型通常由零压梯度或弱逆压梯度边界层标定，在强逆压梯度、分离和再附条件下是否仍然有效并不清楚；分离区近壁速度剖面偏离平衡律，壁面剪应力和热流的模化误差会直接传播到分离泡长度和再附热流。因此需要在典型 SWBLI 构型上系统评估 WMLES 的误差来源。

03本文主要工作

论文采用壁面模化大涡模拟计算典型激波/边界层干扰流动，将近壁区域用壁模型封闭，外层湍流由 LES 解析。通过与全解析 DNS/LES 及实验数据对比，考察平均壁面压力、分离泡长度、壁面摩阻与热流的预测精度；进一步改变网格分辨率和壁模型参数，分析近壁第一层网格尺度、壁面温度条件和来流湍流状态对结果的影响，并讨论 WMLES 在分离区失效的物理原因与可能的修正途径。

04方法与算例细节

控制方程为过滤后的可压缩 N-S 方程，亚格子应力由 LES 模型封闭；近壁区域不解析黏性底层，而由壁模型根据外层速度、密度和温度给出壁面剪应力与热流。计算域覆盖拐角前充分发展湍流边界层、干扰区和下游恢复区，展向取周期条件。网格在分离剪切层和再附区加密，但近壁第一层网格尺度远大于黏性尺度，以体现 WMLES 的工程分辨率。结果与全解析数据在相同来流条件下对比，误差按平均量、脉动量和积分量分别统计。

05推导思路与核心思想

把近壁未解析区域的速度–温度剖面用壁面律或积分壁模型表示，由外层 LES 解提供的速度、密度和温度反推壁面剪应力与热流，从而在工程网格上闭合过滤后的 N-S 方程；通过与传统全解析数据和实验对比，量化壁模型在逆压梯度与分离条件下的误差。

  1. 对可压缩 N-S 方程作空间过滤，得到含亚格子应力与亚格子热通的 LES 方程。
  2. 在近壁区域引入壁模型，以外层速度和温度构造壁面剪应力与热流的代数或积分关系。
  3. 在典型 SWBLI 构型上计算平均压力、分离泡长度、摩阻和热流，并与全解析数据及实验对比。
  4. 改变网格分辨率和壁模型参数，分离数值误差与模化误差。
  5. 根据误差随逆压梯度和分离强度的变化，给出 WMLES 的适用范围与改进方向。

06关键结果与证据

据题录与公开摘要，WMLES 能够以较低计算代价复现干扰区的大尺度结构和平均压力分布，但分离泡长度和再附位置对壁模型与网格分辨率较敏感；在强逆压梯度和回流区，壁模型基于平衡边界层假设给出的剪应力与热流偏差增大，导致峰值热流预测的不确定性高于平均压力。提高近壁分辨率或采用考虑逆压梯度的壁模型可以减小偏差，但计算代价相应上升。论文据此给出 WMLES 用于 SWBLI 时的分辨率建议与误差预期。

07问题、发现与推断

解决的问题：评估了壁面模化 LES 在激波/边界层干扰中预测分离泡与壁面热流的可信度，并识别主要误差来源。

重要发现与推断

  • WMLES 能以较低代价复现干扰区大尺度结构和平均压力。
  • 分离泡长度与再附位置对壁模型和近壁网格分辨率较敏感。
  • 强逆压梯度和回流区是壁模型误差最大的区域。
  • 峰值热流预测的不确定性高于平均压力预测。
  • 采用逆压梯度修正壁模型或提高近壁分辨率可减小偏差。

08本文结论

论文说明壁面模化 LES 可以作为高雷诺数 SWBLI 的工程预测工具，但其可靠性取决于壁模型在逆压梯度和分离条件下的表现；平均压力与大尺度结构较易复现，分离泡长度与峰值热流仍是主要误差来源。工程应用时应针对分离区采用更精细的近壁处理或逆压梯度修正壁模型，并把峰值热流预测视为具有较大不确定性的量。

09适用边界与局限

本文摘要信息有限，具体构型、马赫数、雷诺数与壁模型类型需以原文为准；WMLES 的近壁模化在强分离、非平衡湍流和高速可压缩壁面条件下缺乏严格依据；峰值热流对壁面温度条件和网格分辨率敏感，结论的外推范围受算例限制；未覆盖真实气体、壁面催化和三维复杂构型。
