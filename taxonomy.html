分类体系与检索口径

这套分类不是简单的主题词表，而是围绕两个问题组织：是否发生分离、从何时开始分离、壁面承受多大热流。流态、真实气体效应、建模方式、构型、关注点与年代是六个检索切面；标签用于跨切面检索。

板块

  • 流动分离分离判据、分离泡尺度、三层结构、非定常分离与流动控制（191 篇）
  • 初始分离分离起始条件、初始分离尺度、分离判据与起始点预测；可与流动分离板块叠加（23 篇）
  • 峰值传热再附峰值热流、斜驻点模型、真实气体效应、热防护与实验测量（62 篇）
  • 基础与工具教材、计算工具、纯无粘激波背景，以及无法归入单一板块的交叉文献（69 篇）

三种流态

  • 层流以理论建模、渐近展开、稳定性分析与经典实验为主（99 篇）
  • 转捩关注扰动增长、转捩位置、分离泡非定常与转捩控制（11 篇）
  • 湍流关注分离长度、压力平台、壁面热流与湍流模型（98 篇）
  • 无粘无粘激波反射/干扰、自由干扰与无粘稳定性判据（10 篇）
  • 非定常关注分离泡振荡、低频非定常、运动激波/壁面与全局不稳定性；可同时带层流/转捩/湍流（27 篇）
  • 多流态同时讨论两种以上具体流态，或教材/综述/通用模型等不针对单一流态的工作（84 篇）

真实气体效应

  • 真实气体效应高温真实气体效应的总标签；含以下任一子项时自动加入（36 篇）
  • 壁面催化壁面催化复合对组分扩散与热流的影响（10 篇）
  • 壁面适应壁面能量适应系数、气-壁相互作用（4 篇）
  • 振动能激发振动能激发/松弛对热力学与输运的影响（7 篇）
  • 稀薄气体效应滑移、温度跳跃、DSMC 或非平衡边界条件（13 篇）

关注点标签

用于筛选“这篇文献重点研究哪一种效应”，与流态、构型等对象标签不同；一篇文献可同时关注多种效应。判定要求：文献覆盖较宽的马赫数、雷诺数、壁温等参数范围，并在正文中明确讨论该参数对分离、热流或稳定性的影响；只在算例表中列一个固定值的不计入。

数据来源与边界

文献元数据来自本地 Zotero 库（去重后精选）。摘要优先使用 Zotero 摘要；缺失时从本地 PDF 抽取摘要/结论页。中文摘要为翻译或节译，主要工作与结论为依据原文的结构化提炼。

详情页按 IMRaD 结构组织：阅读说明 → 一句话/三句话 → 核心内容清单 → 引言 → 条件与参数 → 方法 → 核心推导 → 结果与证据 → 机制 → 讨论/局限 → 工程意义 → 核心图件 → 可引用素材 → 核验。公式以 LaTeX 源码保存，页面用本地打包的 KaTeX 渲染（离线，无 CDN）；核心图件由 PDF 按图注位置裁取并回链原页。

已排除 HCW、燃烧、纯爆轰噪声及与 SWBLI 无关的传热/制动/鳍片文献。教材、软件文档与纯无粘激波背景保留在“基础与工具”，用于支撑主板块。

被引数优先来自 OpenAlex（DOI 批量匹配；无 DOI 时按题名 + 年份严格匹配），参考文献数优先来自 Crossref（DOI 匹配，通常更完整），两者都列出以便核对，结果缓存在 build/citation_metrics.json。不同平台收录范围与计数口径不同，未匹配文献不补零；卡片上的“高被引”只是 ≥100 次的浏览阈值，不是学科评价。

日常修改内容后运行 python build/build_site.py 即可；更新被引数据时运行 python build/fetch_citations.py 后再构建；只有重新抓取 Zotero 元数据时，才先运行 python build/prepare_selected.py。
