# SWBLI 文献内容整理规范（供内容撰写使用）

## 目标
为选定的 Zotero 文献条目生成结构化中文内容，供静态网站使用。所有内容必须**基于条目摘要、Zotero 笔记或 PDF 原文**；不得编造具体数值、公式或结论。证据不足时使用谨慎措辞，并在 `evidence` 中说明。

- `F:\文献工具\build\external_meta.json`：73 条外部检索补入的文献元数据（id 2001–2048、学位论文 250/754/755/909 及后续补充），字段与 `selected_meta.json` 相同；构建时按 id 合并，当前总计 218 条。
- `F:\文献工具\build\pdftext\<id>.txt`：部分无摘要文献的 PDF 抽取文本（通常含首页、摘要页、结论页）。
- `F:\文献工具\build\pdftext_all\<id>.txt`：本地 PDF 全文抽取文本，供详情页内容拓展使用。

### 枚举值
- `board`：`["流动分离"]`、`["初始分离"]`、`["峰值传热"]`、`["基础与工具"]`，可多选。`初始分离` 由 `build_site.py` 的 `INITIAL_SEPARATION_IDS` 人工清单叠加，针对以分离起始条件、初始分离尺度或分离判据为主要研究对象的文献；这些文献同时保留 `流动分离`。教材、工具、纯无粘激波背景与无法归入主板块的综述使用 `基础与工具`。
- `focus`：关注点标签，集中维护在 `build/focus_tags.json`（`{"<id>": ["壁温效应", ...]}`），不写入九个内容文件。取值：`马赫数效应`、`雷诺数效应`、`壁温效应`、`轴对称效应`、`三维效应`、`湍流效应`、`动壁效应`、`非定常效应`、`稳定性`、`主动控制`。标注必须是“文中把该参数作为变量并明确讨论其影响”的证据型标签：Mach/Re 至少两个独立条件或覆盖较宽范围且有趋势结论；壁温至少冷/热两条件；轴对称、三维、动壁、非定常须讨论该效应本身（不能只因轴对称构型、三维网格、求解器可算非定常而标注）；湍流须以湍流物理、转捩或湍流建模为主要内容。仅在引言/方法中顺带提到的不标。未标注条目保持为空，构建时**不做**任何按构型或流态的回退，避免把“三维计算”误标成“三维效应”。
- `article_types`：构建时派生，不写入内容 JSON。取值 `教材`、`会议`、`期刊`、`报告`、`综述`、`学位论文`、`预印本`；由 Zotero `type`、出版机构、arXiv 来源与 `review` 标记生成。所有 `report` 类型（NASA、NACA、AGARD、AIAA、大学/实验室报告）统一归入 `报告`，不再按发布机构细分，也不计入 `期刊`；NASA 报告另在期刊目录中带 `NASA报告` 标签。综述同时保留发表载体类型。
- `era`：构建时由 `year` 派生，不写入内容 JSON。`year >= 2000` 为 `2000~至今`，`1900 <= year < 2000` 为 `1900~2000`；2000 年归入前者，两桶互斥。无年份为空并在界面显示“未标注”。
- `venue`：构建时派生。期刊/会议/报告使用刊名或会议名；图书改为“版次; 出版社, 出版地”，不套用卷期。
- 图书元数据：`publisher`、`place`、`edition`、`isbn` 来自 Zotero 或 `meta_overrides.json`；引用时 `book` 类型改用出版社/版次/出版地，中文风格用 `[M]`，BibTeX 用 `@book`。
- `regimes`：可多值数组，取值为 `层流`、`转捩`、`湍流`、`无粘`、`非定常`、`多流态`。构建时旧字段 `regime` 仍可兼容；给出多个具体流态时自动显示为“多流态”。`无粘` 用于纯激波反射/马赫反射与无粘激波干扰研究，`非定常` 用于以分离泡振荡、运动激波/壁面或全局非定常为主线的研究；非定常工作应同时给出层流/转捩/湍流中的相应流态。教材、综述、零维或通用模型等不针对单一流态的工作使用 `多流态`。
- `real_gas`：空数组，或以下子集：`真实气体效应`、`壁面催化`、`壁面适应`、`振动能激发`、`稀薄气体效应`、`化学非平衡`、`振动能非平衡`。含任一子项时同时加入 `真实气体效应`。
- `methods`：`理论建模（控制方程）`、`理论建模（数据驱动）`、`稳定性分析`、`实验研究`、`数值模拟`、`综述`、`教材`、`计算工具`。可多选，首位为主要方法。
- `geometry`：`压缩拐角`、`平板`、`平板入射激波`、`双楔`、`双锥`、`轴对称`、`多构型`、`纯方程`、`其他`。可多选。构型为平板入射激波时，构建脚本会自动同时加入 `平板`；运动平板若属入射激波构型，同样归入 `平板入射激波`；锥/裙、圆锥等回转体加 `轴对称`。教材、综述或覆盖多种构型的对比研究用 `多构型`；无特定几何、仅做方程推导或零维模型的工作用 `纯方程`；鳍、唇罩、交叉激波等特定但不在枚举内的构型用 `其他`。纯平板/运动平板类文献在 `build_site.py` 的 `FLAT_PLATE_IDS` 中维护。
- `tags`：只能从下列受控词表选，可多选，需覆盖 facet：
  `层流, 转捩, 湍流, 无粘, 非定常, 真实气体效应, 壁面催化, 壁面适应, 振动能激发, 稀薄气体效应, 化学非平衡, 振动能非平衡, 流动分离, 传热建模, 经验关联, 数据驱动, 理论建模, 实验研究, 数值模拟, 稳定性分析, 三维效应, 计算工具, 无粘激波干扰, 教材, 综述, 非定常性, 压缩拐角, 平板, 平板入射激波, 双楔, 双锥, 轴对称, 多构型, 纯方程, 课题组文章`
  注意：实验论文加 `实验研究`；数值论文加 `数值模拟`；理论建模加 `理论建模`；综述加 `综述`；教材加 `教材`；计算工具/软件加 `计算工具`；无粘激波反射/马赫反射加 `无粘激波干扰`；无粘流态加 `无粘`；非定常加 `非定常性`。`三维效应` 属于关注点，只在正文明确讨论三维效应时写入 `build/focus_tags.json`，不要仅因三维构型或三维网格添加。`课题组文章` 由作者名自动派生，不要手工写入 content JSON；`Bao Lin / 鲍麟`、`Yu Yong-Liang / 余永亮`、`Wang Zhi-Hui / 王智慧` 视为同一作者，中英文姓名与姓名顺序均做归一化。

### `formula`
若论文提出明确公式/判据/关联式，填对象；否则 `null`：
```json
{"name": "分离长度关联式", "expr": "L/δ ~ ...", "idea": "基本思想与推导步骤，120-260字，说明从哪条守恒关系/量纲分析/渐近展开出发，如何封闭。"}
```
只写论文确实给出的公式；不确定时 `null`，不要编造。

### `derivation_idea` / `derivation_steps` / `problem_solved` / `key_findings`
这四个字段用于详情页的“推导思路与核心思想”和“问题、发现与推断”两节，面向理论建模、稳定性分析与机理类论文：

- `derivation_idea`：一句话说明推导的出发点与核心思想，例如从哪条守恒关系、相似变换、渐近展开或稳定性算子出发，如何封闭。
- `derivation_steps`：3–6 条可核查的推导步骤，按原文逻辑排序；不要只复述结论。
- `problem_solved`：明确指出本文解决的问题（而不是“研究了……”）。
- `key_findings`：3–6 条重要发现、推断或解决的子问题，区分“观测到的事实”与“作者的推断”。

摘要信息不足时可省略 `derivation_steps`，或在 `evidence` 中注明“仅题录”。

`expr` 是纯文本回退与检索字段，保持 Unicode 写法；详情页实际展示的公式来自 `build/formula_latex.py` 中同一 itemID 的 LaTeX 行。新增带公式的文献时，需同时在该文件补一个 `id: [r"..."]` 条目，每行一个公式块。LaTeX 中的中文说明放在 `\text{...}` 内。构建时由 `latex2mathml` 转为 MathML。

### `review`
仅综述/教材/进展类论文填写，否则 `null`：
```json
{"sections": [{"name": "层流分离理论", "summary": "该综述如何划分、主要评述内容，80-160字"}],
 "status": "发展现状，120-260字",
 "gaps": "研究空白与争议，100-220字"}
```
`sections` 2-5 项。一般分离流动综述（如 id 968《分离流动的某些进展》）不属于 SWBLI 专题综述：构建脚本会将其排除出综述页、综述排序与“文章类型=综述”筛选，并在详情页显示范围说明。

### `related`
2-4 个**本批次或全局选定文献**的 itemID，必须真实相关（同一理论脉络、同一构型、同一方法、综述与被综述）。不得填不存在的 ID。

### `evidence` / `confidence`
- `evidence`：`摘要+笔记`、`摘要`、`PDF全文`、`PDF摘要/结论页`、`PDF摘要/目录`、`题录/公开摘要（原文摘要缺失）`、`仅题录`。
- `confidence`：`高`、`中`、`低`。仅题录或信息不足时用 `低`，措辞用“据题名与作者背景推测”之类。

## 写作要求
- 中文为主；术语首次出现可括注英文。
- `formula.expr` 用 Unicode 文本（∂、∑、√、∞、→、×、⁻¹），不要写 `$...$`；正式公式排版写在 `build/formula_latex.py`。
- `abstract_zh` 不是逐字机翻；要通顺、专业、保留定量信息。
- `main_work` 必须区分“做了什么”和“发现了什么”，不要把结论重复写进去。
- 拓展层各字段各司其职：`background` 写问题与缺口，`method_detail` 写数值/实验/理论细节，`findings` 写结果与证据，`limits` 写适用范围与局限；不得用模板化套话替代具体内容。
- 对经典论文（1950-1980），优先依据 PDF 文本；没有 PDF 文本时依据摘要/笔记，仍无则只写题录可支持的内容。
- 对中文文献，摘要可压缩改写，不要照抄大段。
- 教材/专著按“教材”处理：`board=["基础与工具"]`、`regimes=["多流态"]`、`geometry=["多构型"]`、`methods=["教材"]`，概述全书章节与与 SWBLI 相关的章节；只依据目录、前言、版权页和可核实章节，不把教材中的示例数值写成论文结果。
- 不要把 HCW、燃烧、纯爆轰、与 SWBLI 无关的传热/制动/鳍片论文纳入。
- 输出必须是合法 JSON（UTF-8，无注释、无尾逗号）。

## 深度精读层（IMRaD，`build/deep/<id>.json`）

详情页的主内容现由深度精读层驱动；`content_*.json` 的简化字段仍用于卡片、检索与首页摘要，但不再单独决定详情页正文。深度层覆盖 130 篇有可用全文的文献（教材、仅题录、文本为空或过短的条目不进入），按用户给定的 14 部分协议撰写，并组织为 IMRaD：

1. 中文摘要（翻译）与原始摘要；
2. 阅读说明（材料范围、可用图件、截断情况、依据层级）；
3. 一句话核心与三句话摘要（每句标【原文明确】【AI概括】【AI推断】）；
4. 核心内容清单（8–12 条，标 A/B/C 与属性）；
5. 引言：研究问题与领域缺口；
6. 流动条件与几何构型（表）；
7. 核心现象与关键参数（表）；
8. 方法与数据；
9. **核心推导与公式**：`derivation.idea`、`assumptions`、`steps[]`（每步 title/text/latex[]/source）、`result`、`limits`；
10. 结果：主要发现与关键证据；
11. 机制解释与论证链；
12. 讨论：结论、贡献与局限；
13. 对高速流动与工程的意义；
14. 核心图件、可引用原文素材、最终核验、关联文献与引用格式。

硬约束：
- 只依据 `build/deep_input/<id>.md`（题录 + 图件清单 + 带页码全文）与至多 6 页原 PDF 复核；不引外部知识，不编页码、图号、公式、数据与文献；缺失写“文中未提及”，解析不清写“受限于材料，无法确认”。
- 公式与符号一律用 LaTeX，写在 `derivation.steps[].latex` 数组中，元素为**不带 `$` 的纯 LaTeX 源码**；网页用本地 KaTeX 渲染为 `\[...\]` 块。旧版 `formula_latex.py` 的公式仍由 `latex2mathml` 生成 MathML，两套机制并存。
- 原文没有从守恒律出发的解析推导时，`derivation.exists=false`，只列材料中可核对的定义式或建模链，不补写教科书推导。
- `figures[]` 必须取自 `build/figs/<id>/figures.json`，保留 `file/n/page` 原值，并写中文图题与选取理由；每篇 1–4 幅，优先“机理示意 + 结果图”。
